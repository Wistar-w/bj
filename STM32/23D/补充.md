# 波的判断分类（改良版）

> 基于原笔记「排行榜」思路改良。
> 原笔记的骨架（FFT → 取前 N 个峰 → 按峰数/对称/间距分类）是对的，
> 但在真机上直接照抄会掉进几个坑。下面把坑和修法一并写清楚，
> **FSK 单独放在第 5 节重点提醒**。

---

## 1. 前提：先把"图"画对

| 项 | 取值 | 说明 |
|---|---|---|
| 采样率 `fs` | 400 kHz（TIM 触发）或 1 MHz | 必须是**真正**的 fs，不是 ADC 时钟 |
| 点数 `N` | 4096 | 2 的幂 |
| 分辨率 `DF` | `fs / N` | 400k/4096 ≈ 97.7 Hz；1M/4096 ≈ 244.1 Hz |
| 窗 | 汉宁窗 | 主瓣约 **4 bin**，旁瓣只有峰值的 2~3% |

### 1.1 门限必须"双门限"

```c
thr_rel = 0.10f * max_peak;          // 相对：去掉汉宁旁瓣/杂散
thr_abs = NOISE_FLOOR * 2.0f;        // 绝对：无输入时实测的谱峰幅度
thr     = (thr_rel > thr_abs) ? thr_rel : thr_abs;
```

**只用相对门限，永远判不出"无信号"**：纯噪声也有最大值，10% 相对门限
照样能挑出几个"峰"。原笔记里 `if (valid_peaks == 0) return;`
在真机上几乎不会成立，原因就在这里。

### 1.2 载波位置不要写死

实测发生器 50 kHz 可能偏 2~3 kHz。所有"关于载波对称"的搜索都要
**在标称 bin 附近 ±10~15 bin 搜**，平方谱找线更不要写死 `2fc` 的 bin。

---

## 2. 峰排行榜（核心数据结构）

原笔记只存 `idx / mag / peak_num`，不够用。建议每个峰多存一个**半高宽**，
这是后面分 FSK / PSK 的关键。

```c
#define MAX_PEAKS 12

typedef struct {
    uint16_t idx;     // 峰所在 bin
    float    mag;     // 幅度
    uint8_t  width;   // 半高宽（右侧 bin 数，封顶 40）
} Peak;

Peak    peak[MAX_PEAKS];
uint8_t peak_num = 0;
```

### 2.1 找峰（局部极大 + 合并旁瓣）

```c
static void find_peaks(const float *mag, int nbin, float thr)
{
    peak_num = 0;
    for (int k = 2; k < nbin - 2; k++) {
        float m = mag[k];
        if (m < thr) continue;
        if (!(m > mag[k-1] && m >= mag[k+1])) continue;   // 局部极大

        if (peak_num && (k - peak[peak_num-1].idx) < 4) { // 同一主瓣
            if (m > peak[peak_num-1].mag) {
                peak[peak_num-1].idx = k;
                peak[peak_num-1].mag = m;
            }
            continue;
        }
        if (peak_num < MAX_PEAKS) {
            peak[peak_num].idx  = k;
            peak[peak_num].mag  = m;
            peak[peak_num].width = 0;
            peak_num++;
        }
    }
    /* 半高宽 */
    for (int i = 0; i < peak_num; i++) {
        float h = 0.5f * peak[i].mag;
        int k = peak[i].idx, w = 0;
        while (w < 40 && k + 1 + w < nbin && mag[k + 1 + w] > h) w++;
        peak[i].width = w;
    }
}
```

### 2.2 排序

- 按**幅度**降序 → 找前 12 强（决定"谁是边带、谁是载波"）
- 再按**频率**升序复制一份 → 做"等间距 / 对称"判断
- 不要就地只排一次：两种排序都要用

## 3. 判决树（按优先级，这是真机验证过的顺序）

```
0. 无信号？        最强峰 < 绝对门限  或  包络均值 < 绝对门限  → NO SIGNAL
1. 数字键控（先判，否则会被 AM/FM/ASK 抢走）
   1a. 平方谱双音（相隔 >=7 bin、幅度 >25%）        → 2FSK
   1b. 两个窄对称峰 + |IF|中位 >1500 + 包络不是强起伏 → 2FSK
   1c. 载波凹口 + 奇次边带在 + 偶次边带弱            → 2PSK
   1d. 方波包络（env_rail > 0.82）+ 载波在 + ma>1    → 2ASK
2. CW：单峰 / 单线优势比大（最强线 > 次强线 5 倍）
3. AM：恰好 3 峰、对称、中间最高、ma<=1、包络正弦（es>1.18）
4. FM：>=4 峰、等间距、包络平（rel<0.12）、IF 正弦（if_rel>1）
5. 都不满足 → UNKNOWN（★ 不要兜底成 2PSK）
```

### 3.1 原笔记里需要纠正的地方

| 原写法 | 问题 | 改法 |
|---|---|---|
| `valid_peaks == 0` 判无信号 | 相对门限下永不为 0 | 加绝对门限 |
| "2 个峰且距离 <5 bin → PSK" | 真 BPSK 是宽带隆起，不是两个近峰；反而会把小 h 的 FSK 判成 PSK | PSK 看"载波凹口 + 奇次边带 + 偶次弱" |
| "峰数 >=4 → FM" | 噪声/1010 的 ASK/PSK 也 ≥4 峰 | 等间距 + 对称 + 包络平 + 绝对门限 |
| 没查 `ma` | 1010 的 2ASK 等效 ma≈4/π≈1.27，会被判 AM | `ma > 1 → 2ASK` |
| 排行榜在包络/时域之前无条件生效 | 1010 数字键控谱线同样"3 根/多根"，会被 AM/FM 抢 | 每类加**类型守卫**（见下） |

### 3.2 类型守卫（真机实测值，50 kHz）

| 判成 | 必备守卫 |
|---|---|
| 2FSK | `g_sq_two`（平方谱双音）**或** `两个窄对称峰 + abs>1500`；且 `rel<0.55` |
| 2PSK | 载波凹口（`Ec/E1<0.30`）+ 偶次边带弱（`E2/E1<0.15`）+ 奇次边带在（`E3/E1>0.03`） |
| 2ASK | `env_rail>0.82` 且 `ma>1` 且载波在 |
| AM | `es>1.18` 且 `ma<=1` 且峰数<=3 |
| FM | `if_rel>1.0` 且 `rel<0.12` 且峰等间距 |
| CW | 包络平（rel<0.12）+ 频率平（if_rel<0.10）+ 单线优势 |

> 守卫之间会互相"抢"，顺序很重要：**数字键控先判，模拟后判**；
> FSK/PSK 谁先判取决于你要保护谁，实践里**先 FSK 再 PSK**。

## 4. 参数估计

| 模式 | 参数 | 方法 |
|---|---|---|
| AM | `F` | 左右边带间距 `(kr-kl)/2 × DF` |
| AM | `ma` | `(A_left + A_right) / A_carrier` |
| FM | `F` / `mf` / `Δfmax` | IF 匹配滤波（1~5 kHz 候选） |
| 2ASK / 2PSK | `Rc` | 谱线间距吸附到候选码率 |
| 2FSK | `Rc` | 谱线间距 / 平方谱两线间距 ÷ 2 |
| 2FSK | `h` | `Δf / Rc`，见第 5 节 |

**Rc 候选表**：题目是 6/8/10 kbps；自己调试可能用 3/4/5 kHz，建议一起放：

```c
static const float RC_CAND[] = {3000, 4000, 5000, 6000, 8000, 10000};
```

间距可能等于 `Rc`，也可能等于 `2×Rc`（不同码型/约定）。
**6 kHz 的间距会同时匹配 "Rc=6k" 和 "2×Rc=3k"** ——
这时要**优先按"间距=Rc"解释**，否则会两个都命中然后返回 0，
表现为 `Rc=0 / h=0`。

## 5. ★ FSK 特别提醒（重点看这里）

### 5.1 最容易踩的坑：FSK 和 PSK 在频谱上可能一模一样

1010 码型的 2PSK 和 2FSK，频谱都是**窄的、关于载波对称的谱线**：

| 特征 | 真 2FSK | 2PSK（1010） |
|---|---|---|
| 峰数 | 2 个（两个载频） | 2~多根（边带） |
| 峰宽 | 窄 | 窄 |
| 间距 | `h·Rc/2` 两侧 | `Rc/2` 两侧 |
| 载波 | 可能没有 | 被抑制（凹口） |

**只靠峰数 / 峰宽 / 峰距，分不开。**
我在这上面绕了很久，最后靠下面这条才切开。

### 5.2 最终判据：平方后做 FFT

对时域信号平方再 FFT：

```
2PSK: (±180° 翻转被平方消掉)  → x² 只剩一个 2fc 单音     → 一条线
2FSK: x² = 两个单音 2f1 / 2f0  → 关于 2fc 对称的两条线
2ASK: 包络还在                  → 2fc 两侧有 Rc 间隔边带   ← 注意！
```

代码要点：

```c
/* 1. 去直流，归一化，平方，加汉宁窗 */
for (i = 0; i < N; i++) {
    float x = ((float)adc[i] - mean) / 600.0f;
    buf[2*i]     = x * x * hann[i] * SCALE;
    buf[2*i + 1] = 0;
}
/* 2. FFT + 取模 */
fft(buf, N);
for (i = 0; i < N/2; i++) buf[i] = sqrtf(re*re + im*im);

/* 3. 在 50~160 kHz 范围内找【最强两条线】（不要写死 2fc！）
 *    第二条 > 第一条的 25% 且相隔 >= 7 bin  -> 双音 -> 2FSK */
```

**别写死 `2fc` 的 bin**：发生器载波可能偏 2~3 kHz，
写死了就找不到"对称"，真 FSK 会被漏掉。

### 5.3 2ASK 也会骗过平方判据

2ASK 平方后包络还在，也会出两条边带。所以 2FSK 还必须**看包络**：

```c
rel = 包络交流 rms / 包络均值;        // 或 max-min 的相对量
2ASK : rel ≈ 0.6 ~ 0.9               // 通断包络
2FSK : rel ≈ 0.01 ~ 0.30             // 跳频时镜像也会拍出起伏
```

实践门限：**`rel < 0.55` 才算 FSK 候选**。
如果发生器换频时相位不连续、起伏更大，用更稳的量：

```
erv = 包络双电平占比（p5/p95 轨外比例）
2ASK : erv ≈ 0.96
2FSK : erv ≈ 0.42
门限 0.80 分得很开
```

### 5.4 h 不要直接用 |IF| 中位数

`abs = |IF| 中位数` 会随**码型偏置**变化：一帧偏 1，中位值≈Δf；
另一帧过渡点多，就掉到 0.5Δf。结果 `h = abs/Rc` 在 1/2 之间跳。

**稳的做法（按优先级）**：

```
① 平方谱两条线：|f1-f0| = 0.5 × |k2-k1| × DF
                 h = 0.5 × |f1-f0| / Rc
② 没有平方谱：h = abs / Rc，并把结果夹在题目范围 2~5
③ 绝对不要用"时域 IF 上下半中位数"算 sep —— 真机上它只量到大约 Δf，
   会让 h 系统偏小一半。
```

### 5.5 FSK 的 Rc 与"2 倍"约定

- 谱线间隔 = `Rc`（普通）或 `2×Rc`（某些码型/约定）
- 6 kHz 的间隔会同时匹配 `Rc=6k` 与 `2×3k`
- **优先直接解释**，只在直接解释不成时才用 2×

### 5.6 FSK 判错时按这个顺序查

| 现象 | 优先怀疑 | 处理 |
|---|---|---|
| 跳 PSK | `rel` 门限太紧 / 平方谱没测到 | `rel<0.55`，或用"两窄对称峰 + abs>1500" |
| h=0 | Rc=0 / abs 太小 | 看 FP 的 `gv`、`abs`；Rc 先修 |
| h 在 1、2 之间跳 | abs 是 |IF| 中位数，随码型变 | 夹到 2~5，或改用平方谱 |
| h 偏大一倍 | 把 `|f1-f0|/Rc` 当成了 `Δf/Rc` | h 统一用 **Δf/Rc**（发生器面板口径） |
| 判成 AM | `ma` 用了 2ASK 的等效调制度 | `ma>1 → 2ASK` |
| 判成 CW | 只看到一根线 | 谱峰合并太宽 / 门限太高，看 `np`、`g` |

### 5.7 调试打印建议（FP 行）

至少打这 8 个量，出问题时一眼看出卡在哪：

```
rel  = 包络相对起伏
es   = 包络正弦度
erv  = 包络双电平占比
rail = IF 双电平占比
ifr  = IF 正弦度
abs  = |IF| 中位数
np/g = 谱峰数 / 前四条间隔
g2   = 平方谱是否双音
```

> 注意：`2B FM vpp=... cyc=... mf=...` 这类行是 **DAC 解调输出自检**，
> 非 AM 模式也会硬打 "FM" 标签 —— **别把它当识别结果**。

## 6. 代码骨架汇总

```c
void analyze(const uint16_t *adc)
{
    /* 1. 去直流 + 汉宁窗 + FFT + 幅度谱 mag[] */
    /* 2. 双门限 */
    float amax = max(mag);
    if (amax < ABS_FLOOR) { show("NO SIGNAL"); return; }
    float thr = max(0.10f * amax, ABS_FLOOR);
    /* 3. 峰排行榜 + 半高宽 */
    find_peaks(mag, N/2, thr);
    /* 4. 结构判据（顺序见第 3 节） */
    /* 5. 参数（AM: F/ma；FM: F/mf/df；数字: Rc / h） */
}
```

## 7. 一页速查

```
无信号   : 最强峰 < 绝对门限
CW       : 1 峰，或单线优势比 >5
AM       : 3 峰对称、中间最高、es>1.18、ma<=1
FM       : >=4 峰等间距、rel<0.12、if_rel>1
2ASK     : 方波包络(erv>0.82)、载波在、ma>1
2PSK     : 载波凹口 + 奇次边带 + 偶次弱
2FSK     : 平方谱双音（首选）或 两窄对称峰+abs大+rel<0.55
都不满足 : UNKNOWN（绝不兜底成 2PSK）
```
